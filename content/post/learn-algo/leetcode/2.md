给你两个**非空**的链表，表示两个非负的整数。它们每位数字都是按照**逆序**的方式存储的，并且每个节点只能存储**一位**数字。

请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

**示例 1：**

![](/imgs/learn-algo/leetcode/ScreenShot_2026-10-10_143439_669.png)

> 输入：l1 = [2,4,3], l2 = [5,6,4] \
> 输出：[7,0,8] \
> 解释：342 + 465 = 807.

**示例 2：**

> 输入：l1 = [0], l2 = [0] \
> 输出：[0]

**示例 3：**

> 输入：l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9] \
> 输出：[8,9,9,9,0,0,0,1]

**提示：**

- 每个链表中的节点数在范围 [1, 100] 内
- $0 \leq Node.val \leq 9$
- 题目数据保证列表表示的数字不含前导零

## 解法

思路：

- 模拟竖式加法，从个位开始，逐位相加
- 处理进位，将进位传递到下一位
- 链表长度不同，如 l1 长度为 m，l2 长度为 n，且 m > n 时，则将 l2 的后 m-n 位按 0 值处理
- 最后一位存在进位，需要在链表末尾添加一个节点

```python
class Solution:
    def addTwoNumbers(self, l1: ListNode | None, l2: ListNode | None) -> ListNode | None:
        head = ListNode(0)
        current = head
        carry = 0

        while l1 or l2 or carry:
            v1 = l1.val if l1 else 0
            v2 = l2.val if l2 else 0

            total = v1 + v2 + carry
            carry = total // 10
            current.next = ListNode(total % 10)
            current = current.next

            if l1: l1 = l1.next
            if l2: l2 = l2.next

        return head.next
```

* 时间复杂度：$O(\max(m, n))$
* 空间复杂度：$O(\max(m, n))$
* `//` 为整除运算符，返回商的整数部分，算进位
* `%` 为取余运算符，返回除法的余数，算当前位的数值
